How to get a FREE Google Gemini API Key (Includes Gemma Backup Models)
  1. Go to Google AI Studio (aistudio.google.com/apikey) and sign in with your regular Google account.
  2. Click “Create API key”, copy the key (starts with AIza...), and paste it above.
  3. Tip for 503 High Demand spikes: Click Test Key & Find Working Model above! FeastSync now also supports Google’s free Gemma 3 models (e.g., gemma-3-27b-it) on the exact same key, which use a separate server pool and rarely hit Gemini Flash’s 503 spikes.
Still seeing 503s? Try Groq or Copy & Paste Mode above! Open Google AI Studio
How to get a FREE Groq API Key (Very fast & reliable, no credit card)
  1. Go to console.groq.com/keys and sign in with Google or GitHub (free tier, no credit card required).
  2. Click “Create API Key”, name it FeastSync, and copy the key (starts with gsk_...).
  3. Paste it above — FeastSync will pull live Llama & Qwen models automatically.

How to get a FREE OpenRouter API Key (Access dozens of :free models)
  1. Go to openrouter.ai/keys and sign in for free.
  2. Click “Create Key” and paste it above (starts with sk-or-...).
  3. Keep Free-tier models only checked to automatically filter to zero-cost :free models with auto-fallback.
